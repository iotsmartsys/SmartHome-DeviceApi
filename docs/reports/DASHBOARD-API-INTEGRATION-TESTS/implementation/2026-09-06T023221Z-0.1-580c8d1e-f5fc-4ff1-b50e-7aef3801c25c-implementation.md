## Limitações e estado

A suíte não cobre exaustivamente os onze critérios da API. Padrão global,
fixtures de conversão/precedência, alteração/remoção da fonte, cascade físico
e falhas de infraestrutura estão fora da cobertura desta versão. O exemplo
gauge depende da capability selecionada e sua não aplicabilidade fica registrada
no resultado de IT-07. Restante do cenário verifica merge/reset comum.

Execução futura depende de destino, schema/catálogo e fonte já preparados.
Manifesto deve ser preservado; alteração manual do marcador exige reconciliação
humana. Run e cleanup não concorrem no mesmo manifesto. Uma escrita HTTP que
termine depois de uma interrupção pode exigir nova chamada de cleanup.

nem substitui evidências de outros domínios. Nenhum aceite, encerramento Done
