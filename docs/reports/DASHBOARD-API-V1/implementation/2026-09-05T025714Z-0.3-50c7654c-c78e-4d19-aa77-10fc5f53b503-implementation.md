## Decisões locais de implementação

- Novos arquivos estão junto aos precedentes: Api/Controllers, Models e
  Middlewares; Core/Entities, Services, Exceptions e Contracts/Repositories;
  Data.Repositories/Repositories e Queries. Nenhuma dependência de pacote nova.
- Bloqueio transacional em `dashboard_write_lock`, específico do domínio,
  serializa todas as escritas Dashboard, inclusive entre instâncias. Isolamento
  ReadCommitted preserva campos omitidos depois do escritor anterior. O índice
  gerado `default_slot` admite vários nulls e no máximo um padrão verdadeiro.
  Leitura da fonte durante escrita usa LOCK IN SHARE MODE até o commit.
- O repositório usa projeção Dashboard própria sobre Capabilities, CapabilityTypes
  e Devices, preservando queries antigas. Nenhuma alteração de schema das fontes.
- Modelos HTTP são serializados localmente com System.Text.Json; não se altera
  a configuração global Newtonsoft que ignora nulls. Middleware novo fica no
  pipeline após o handler existente e trata somente as rotas Dashboard.
- Timestamps persistidos são truncados a microssegundos, compatíveis com
  DATETIME(6), para POST e GET conservarem o mesmo instante. Fonte DATETIME
  sem offset exige SourceTimeZone; erro de configuração segue o contrato.
- Conversão float aceita a faixa finita de double; labels usam arredondamento
  decimal quando representável, preservando o meio para longe de zero.
  Int64 mantém precisão na saída JSON e na formatação textual.
