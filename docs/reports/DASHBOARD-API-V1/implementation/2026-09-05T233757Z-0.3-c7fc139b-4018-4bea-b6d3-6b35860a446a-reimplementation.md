## Precedentes adotados e exceções delimitadas

| Dimensão | Precedente concreto | Aplicação |
|---|---|---|
| Entrada e modelos | `Api/Models/Group.cs`, `Settings.cs`, `ISelfValidate.cs` | Models explícitos de Dashboard, Widget, Position e Config; requests de criação/atualização separados das respostas; conversão explícita para o Core. |
| Controllers | `GroupController.cs`, `CapabilityTypeController.cs` | ApiController, rotas por recurso, métodos Get/Add/Update/Delete com sufixo Async, FromBody/FromRoute/FromServices, ProducesResponseType e resultados MVC Ok/CreatedAtRoute/NoContent. |
| Serviço e domínio | `IAddCapabilityService`, `AddCapabilityService`, `Core/Entities/Capability.cs` | Interfaces registradas no CoreDI; entidades Dashboard/Widget com estado tipado, validação e aplicação de alterações. |
| Persistência | `IGroupRepository`, `GroupRepository`, `GroupQuery` | Métodos explícitos, Dapper/CommandDefinition, cancellationToken, transações, rollback e fechamento de conexão; queries em classes por recurso; tabelas/colunas PascalCase. |
| Presença de campos | Flags de atualização de `IGroupRepository.UpdateAdministrativeAsync` | Contratos Core guardam valor e presença, preservando omitido/null mesmo para booleanos e inteiros. |

Rotas literais, nomes JSON camelCase e envelopes seguem o contrato explícito da
0.3. A implementação usa a organização e os padrões internos do código sem
alterar as rotas de APIs anteriores. O precedente snake_case de alguns payloads
antigos não substitui silenciosamente o contrato wire da especificação.

O binding permissivo de Newtonsoft pode converter números em strings e não
representa sozinho omitido/null. Um converter restrito aos modelos Dashboard
valida tipos/chaves JSON antes do binding; JSON genérico não atravessa o contrato
público do controller nem os serviços/Core. Respostas são records explícitos,
com inclusão local de nulls. O filtro local normaliza erros de binding e mídia;
nenhum formato global de erro/serialização é alterado.

A transação aplica o request sobre a entidade relida sob bloqueio para evitar
perda de campos em PUT concorrente. O contrato público genérico WithWriteLock
foi removido. Índice único preserva no máximo um padrão; zero continua válido.
LEFT JOIN é mantido na projeção das fontes porque INNER JOIN esconderia fontes
parcialmente ausentes, contrariando os status exigidos. Configuração persistida
ilegível é marcada na entidade para produzir erro do item na renderização.
Não foram introduzidas camadas transversais ou dependências de pacote.
