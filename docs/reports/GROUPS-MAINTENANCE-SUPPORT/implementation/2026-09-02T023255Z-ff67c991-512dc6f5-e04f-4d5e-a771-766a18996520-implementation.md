> Este relatório registra uma atuação e não altera fontes normativas.

## Resultado implementado

A Device API passa a retornar `200 []` para coleção vazia; recebe criação sem
`id` ou `capabilities`, preservando capabilities legadas opcionais; persiste
`IconName`; restringe PATCH a `replace` de `name`, `active` e `icon`; produz
`ProblemDetails` para validação e ausência; e exclui Group e relações em
transação explícita sem excluir capabilities.

## Arquivos e contratos afetados

- `src/Api/Models/Group.cs`: DTOs distintos de criação e patch, mantendo
  `Group` como leitura e contrato do PUT legado.
- `src/Api/Controllers/GroupController.cs`: guards, normalização, allowlist,
  respostas HTTP e schemas declarados por operação.
- `src/Core/Contracts/Repositories/IGroupRepository.cs` e
  `src/Data.Repositories/Repositories/GroupRepository.cs`: PATCH administrativo
  por campo e DELETE transacional com resultado de existência.
- `src/Data.Repositories/Repositories/Queries/GroupQuery.cs`: INSERT de
  `IconName`, updates isolados e lock do Group durante PATCH.
- `src/Api/Program.cs`: schema OpenAPI local do JSON Patch de Groups.
- especificação, changelog, mapa e dossiê receberam somente estado e fatos da
  atuação.

## Evidências produzidas

- `dotnet build src/Api/Api.csproj --configuration Release`: sucesso, código de
  saída `0`; Core, Data.Repositories e Api construídos para `net9.0`.
- O build final registrou um aviso preexistente em
  `CapabilityHistoryController.cs:6` e zero erros.
- `git diff --check`: aprovado.
- Inspeção do delta confirmou ausência de alterações em `tests/`, PUT e rotas
  de associação.

## Decisões locais

- O modelo `Group` foi preservado para leitura e PUT; somente POST e PATCH
  receberam DTOs próprios.
- PATCH executa somente os comandos dos caminhos presentes e usa uma transação
  com lock do recurso para distinguir desaparecimento concorrente.
- DELETE remove relações explicitamente antes do Group na mesma transação,
  sem depender de cascade não comprovado.
- O schema do tipo fechado `JsonPatchDocument<GroupPatchRequest>` foi mapeado
  no bootstrap, sem criar filtro ou política OpenAPI transversal.
