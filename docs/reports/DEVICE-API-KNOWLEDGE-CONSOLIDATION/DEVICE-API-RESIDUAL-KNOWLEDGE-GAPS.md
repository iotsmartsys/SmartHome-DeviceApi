## Estado de uso

As lacunas acima são delimitadas por autoridade e evidência resolutiva. Não se usa a ausência de execução de testes para deixar indefinido o comportamento interno determinado por código. A [auditoria](../DEVICE-API-DOCUMENTATION-AUDIT/2026-11-24-43fbdc0/DEVICE-API-DOCUMENTATION-AUDIT.md) mantém seus ensaios isolados e limites; os arquivos históricos, as especificações e o OpenAPI não foram reescritos nesta consolidação.
